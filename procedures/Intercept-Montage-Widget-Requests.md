# Intercept-Montage-Widget-Requests

## Summary

This procedure uses a proxy tool to capture HTTP requests generated by Vimeo's montage widget tool, revealing parameters like 'badge_channel' for potential manipulation in IDOR attacks.

## Description

Access the montage widget at https://vimeo.com/tools/widget/montage while proxying traffic through Burp Suite. Interact with the tool (e.g., select channel stream) to trigger requests. This exposes the backend endpoint and query parameters without authentication checks. Prerequisites include Burp Proxy setup and a logged-in session. Outcome: Intercepted requests ready for analysis.

## Requirements

1. Burp Proxy installed and running
2. Browser configured to use proxy (e.g., 127.0.0.1:8080)
3. Logged-in Vimeo account

## Defense

Defensive measures and detection strategies:

- Monitor for unusual proxy traffic patterns or high request volumes to widget endpoints
- Enforce HTTPS and certificate pinning to hinder interception

## Objectives

1. Capture montage widget HTTP requests
2. Identify manipulable parameters
3. Prepare for parameter tampering

## Instructions

### Step 1: Configure Proxy and Access Widget

**Context**: Route traffic to intercept requests during widget use.

No command; set browser proxy to Burp and visit https://vimeo.com/tools/widget/montage.

> Requests appear in Burp's Proxy tab, including the second request to the montage endpoint.

**Expected Output**: List of HTTP requests with details like GET/POST to /tools/widget/montage.
