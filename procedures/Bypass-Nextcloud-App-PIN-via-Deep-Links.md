# Bypass Nextcloud App PIN via Deep Links

## Summary

This procedure exploits a vulnerability in the Nextcloud Android app that allows bypassing the app PIN authentication using deep links generated by third-party applications, enabling unauthorized access to the app's contents without entering the PIN.

## Description

The Nextcloud Android app implements app-level PIN protection to secure access to user data. However, due to insufficient validation of deep links from external sources, third-party apps can generate and trigger deep links (e.g., in the `nextcloud://` scheme) that open the app directly, skipping the PIN prompt. This was reported in HackerOne report #1825679 on January 7, 2023, with a CVSS score of 1.8 (low severity). The attack requires access to the target Android device and the ability to use or install a third-party app that supports deep link generation. Successful exploitation grants immediate access to the app's interface and data, potentially exposing sensitive files if the app is not further protected.

## Requirements

1. Android device with Nextcloud app installed (version affected: pre-patch as of 2023)
2. App PIN enabled in Nextcloud settings
3. Access to install or use a third-party app (e.g., Tasker, IFTTT, or any app with deep link intent capabilities)
4. Basic knowledge of Android intents and deep link schemes

## Defense

Defensive measures and detection strategies:

- Update the Nextcloud Android app to the latest version where the vulnerability is patched
- Disable or restrict third-party app access to deep links via Android settings (e.g., app permissions for intents)
- Monitor device logs for unusual deep link invocations using Android Debug Bridge (ADB) or security tools like MobSF
- Enforce device-level security such as biometric auth over app PIN

## Objectives

1. Bypass the app PIN to gain unauthorized entry into the Nextcloud app
2. Access app functionality and user data without authentication
3. Demonstrate the risks of improper deep link handling in mobile applications

## Instructions

### Step 1: Identify or Install Third-Party App

**Context**: Select an app that can generate custom deep links to Nextcloud. Common examples include automation apps like Tasker or file managers that support intent-based sharing.

Install the app from the Google Play Store if not present, and ensure it has permissions to create intents or deep links.

### Step 2: Generate Deep Link

**Context**: Craft a deep link using the Nextcloud URI scheme. The scheme typically follows `nextcloud://[action]/[parameters]`, such as `nextcloud://open` to launch the main activity.

In the third-party app, configure an action to create and trigger the intent. For example, in Tasker: Create a new task with a "Send Intent" action, set Action to "android.intent.action.VIEW", Data to "nextcloud://open", and Target to the Nextcloud app package (`com.nextcloud.client`).

### Step 3: Trigger the Deep Link

**Context**: Execute the deep link to launch Nextcloud, observing if the PIN prompt is skipped.

Run the task or action in the third-party app. The Nextcloud app should open directly to its main screen or the linked content without prompting for the PIN.

**Expected Output**: Nextcloud app interface loads without authentication barrier, allowing navigation to files, settings, or synced data.

### Step 4: Verify Access

**Context**: Confirm unauthorized access by attempting to view protected content.

Navigate within the app to access files or accounts. If successful, the bypass is confirmed.

**Expected Output**: Full app functionality available, including file browsing and sync operations.
