# Register Concatenated Domain to Intercept Codes

## Summary

This procedure involves registering the predictable concatenated domain generated by the OAuth redirect, allowing the attacker to set up a server that captures authorization codes sent during user approval, enabling token exchange and unauthorized access.

## Description

Exploiting developer errors in omitting protocols, the malformed redirect points to domains like 'www.coinbase.comexample.com'. By registering this domain quickly, the attacker can host a phishing or capture page to steal the OAuth code, which can then be exchanged for access tokens, compromising user accounts with high impact on authentication.

## Requirements

1. Predicted concatenated domain name (e.g., www.coinbase.comprashanthvarma.in)
2. Access to a domain registrar and web server hosting
3. Knowledge of OAuth token exchange endpoint

## Defense

Defensive measures and detection strategies:

- Prevent protocol-less URIs in registration and enforce HTTPS-only redirects
- Monitor for unusual domain registrations related to your brand
- Implement code validation and short-lived tokens

## Objectives

1. Secure control over the malformed domain
2. Intercept and capture the authorization code
3. Exchange code for access token to gain user data access

## Instructions

### Step 1: Identify Target Domain

**Context**: Determine the exact concatenated domain from the redirect.

From the prior step, note the full malformed URL, e.g., `www.coinbase.comprashanthvarma.in`.

### Step 2: Register Domain

**Context**: Purchase and configure the domain for immediate use.

Use a registrar like GoDaddy to search for and register `www.coinbase.comprashanthvarma.in` (or equivalent). Point DNS to your server IP.

### Step 3: Set Up Capture Server

**Context**: Host a page to receive and log the redirect with code.

Deploy a simple web server (e.g., using PHP or Node.js) at `/code.php` to log query parameters, including the `code` from OAuth.

> When a user authorizes, the GET request includes `?code=AUTH_CODE`, which you capture.

### Step 4: Exchange Code for Token

**Context**: Use the intercepted code to obtain tokens.

POST to Coinbase token endpoint with `grant_type=authorization_code`, `code=<intercepted_code>`, `redirect_uri=<original>`, `client_id=<id>`.

**Expected Output**: Access token and refresh token returned, granting scope=user access.
