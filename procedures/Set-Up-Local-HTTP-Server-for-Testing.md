# Set-Up-Local-HTTP-Server-for-Testing

## Summary

This procedure sets up a simple local HTTP server using Python's built-in SimpleHTTPServer module to act as a target for testing curl's globbing vulnerability, allowing observation of incoming request floods.

## Description

In the context of reproducing the curl URL globbing DoS vulnerability, a local HTTP server is needed to receive the massive volume of requests generated by curl's expansion of large range patterns like [1-9999999999999999999]. The server logs all incoming connections, enabling verification of the exploit's impact on resource consumption. This setup requires Python installed on a Linux system and uses port 8000 by default.

## Requirements

1. Python 2.x or 3.x installed (SimpleHTTPServer is built-in)
2. Port 8000 available and not in use
3. Local network access (localhost)

## Defense

Defensive measures and detection strategies:

- Firewall rules to restrict inbound traffic on test ports like 8000
- Monitoring for unexpected HTTP servers in logs or processes

## Objectives

1. Create a target endpoint for curl requests
2. Log incoming traffic for analysis
3. Simulate a vulnerable third-party site

## Instructions

### Step 1: Start the HTTP Server

**Context**: Launch the server to listen for HTTP requests on port 8000, preparing it to handle the incoming flood from curl.

**Command** ([[commands/python-simplehttpserver-start]]):
```bash
python -m SimpleHTTPServer 8000
```

> This command invokes Python's SimpleHTTPServer module, binding to all interfaces on port 8000. Expected output includes a startup message confirming the server is serving HTTP, followed by request logs in the format '127.0.0.1 - - [timestamp] "GET /path/ HTTP/1.1" 200 -' for each hit.
