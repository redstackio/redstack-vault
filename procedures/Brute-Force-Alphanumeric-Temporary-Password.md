# Brute-Force-Alphanumeric-Temporary-Password

## Summary

This procedure exploits the low entropy of alphanumeric-only temporary passwords generated by the MTN Group reset mechanism by systematically guessing combinations to achieve unauthorized login.

## Description

The temporary passwords are limited to lowercase letters and digits (36 characters), typically 6-8 characters long, resulting in manageable search spaces (e.g., 36^8 ≈ 2.8 trillion, but feasible with targeted scripting or manual trials for short lengths). This procedure assumes the reset has been initiated; it focuses on login attempts without email access. Use browser tools for automation. Expected outcome: Account access via guessed credential, highlighting the brute force vulnerability.

## Requirements

1. Target user ID
2. Web browser with developer console for scripting guesses
3. Basic scripting knowledge for automation (optional but recommended)

## Defense

Defensive measures and detection strategies:

- Enforce lockouts after failed login attempts
- Use complex temporary passwords with specials and expiration
- Monitor login failures for patterns indicating brute force

## Objectives

1. Guess the temporary password
2. Gain initial access to the account
3. Demonstrate entropy weakness

## Instructions

### Step 1: Prepare Guess List

**Context**: Generate potential alphanumeric combinations based on observed length.

Manually list or script simple combinations (e.g., start with 6-char: '000000' to 'zzzzzz').

> Focus on common patterns; full brute force may require external tools like custom Python scripts.

### Step 2: Attempt Logins

**Context**: Submit guesses to the login form.

On the login page, enter user ID and a guess as password, then submit. Repeat for each combination.

> Invalid guesses show error; valid one proceeds to password change.

### Step 3: Automate if Possible

**Context**: Speed up with browser console.

Open dev tools (F12), use JavaScript to loop form submissions with generated strings.

> Example console snippet: for(let i=0; i<1000; i++) { /* fill form and submit */ } – adapt to site.
