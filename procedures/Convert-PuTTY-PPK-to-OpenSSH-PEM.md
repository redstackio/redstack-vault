# Convert-PuTTY-PPK-to-OpenSSH-PEM

## Summary

This procedure converts private keys stored in PuTTY's .ppk format to the OpenSSH-compatible .pem format, enabling their use with tools like OpenSSH clients on Linux systems. It is commonly needed when transferring keys from Windows-based PuTTY environments to Unix-like systems for SSH access during security assessments or remote operations.

## Description

PuTTY, a popular SSH client on Windows, saves private keys in a proprietary .ppk format that is not directly compatible with OpenSSH, the standard SSH implementation on Linux and other Unix-like systems. This conversion is essential for red teamers or administrators who need to use existing PuTTY-generated keys with command-line SSH tools, such as ssh or scp, without regenerating keys. The process leverages puttygen, a utility from the PuTTY suite, to perform the format conversion while preserving the key's integrity and passphrase if present. This technique supports lateral movement or remote access scenarios where SSH keys are involved, ensuring seamless integration across platforms.

## Requirements

1. Debian-based Linux distribution (e.g., Ubuntu, Kali) with apt package manager.
2. Administrative privileges (sudo access) for package installation.
3. Existing .ppk private key file generated by PuTTY.
4. Putty-tools package installed, which includes puttygen.

## Defense

Defensive measures and detection strategies:

- Monitor for unauthorized key conversions or SSH key usage in logs (e.g., via auditd or SSH server logs).
- Enforce key management policies, such as using hardware security modules (HSMs) or centralized key stores to limit local key handling.
- Detect anomalous puttygen executions through endpoint detection tools monitoring for process creation events involving putty-tools.

## Objectives

1. Install the necessary putty-tools package to enable key conversion capabilities.
2. Convert the .ppk file to .pem format without altering the key's cryptographic properties.
3. Verify the converted key for compatibility with OpenSSH tools.

## Instructions

### Step 1: Install Putty Tools

**Context**: Ensure the puttygen utility is available by installing the putty-tools package on a Debian-based system. This step requires internet access for package download.

**Code** ([[codes/install-putty-tools-debian]]):

```bash
apt update && apt install putty-tools -y
```

> This command updates the package list and installs putty-tools. Expected output includes confirmation of installation, such as "putty-tools is already the newest version" if previously installed, or download progress followed by "Setting up putty-tools".

### Step 2: Convert the PPK Key to PEM Format

**Context**: Use puttygen to perform the format conversion. Replace $_KEY with the base name of your .ppk file (e.g., mykey for mykey.ppk). The output will be a new .pem file with the same base name.

**Command** ([[commands/puttygen-convert-ppk-to-pem]]):

```bash
puttygen $_KEY.ppk -O private-openssh -o $_KEY.pem
```

> If the key has a passphrase, you will be prompted to enter it. Expected output is a silent success (no stdout message) or an error if the input file is invalid. Verify by checking file creation with `ls -la $_KEY.pem` and testing the key with `ssh-keygen -y -f $_KEY.pem` to display the public key.

### Step 3: Verify Conversion

**Context**: Confirm the .pem file is valid and usable with OpenSSH by extracting its public key or attempting an SSH connection.

**Command**:

```bash
ssh-keygen -y -f $_KEY.pem
```

> This displays the public key if successful. Expected output starts with "ssh-rsa" or similar, followed by the key data. If passphrase-protected, enter it when prompted. Success confirms the key is in correct PEM format.
