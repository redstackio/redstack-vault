# Intercept-Follow-Request-with-Burp-Suite

## Summary

This procedure uses Burp Suite to intercept and capture the HTTP POST request generated by a follow/like action on a Judge.me user profile, allowing analysis of the request for subsequent exploitation.

## Description

Burp Suite acts as a proxy to monitor and intercept web traffic. By configuring the browser to route through Burp and performing a follow action, the outgoing request to the follow endpoint (likely a POST to /people/follow or similar) is captured. This reveals headers, payload (e.g., user IDs, tokens), and allows modification if needed. The target environment is the web-based Judge.me platform, with prerequisites including Burp Suite installation and proxy setup. Success results in a detailed view of the request, ready for replay in the race condition exploit.

## Requirements

1. Burp Suite installed and running
2. Browser configured to use Burp as proxy (e.g., 127.0.0.1:8080)
3. Access to Judge.me people page from previous procedure

## Defense

Defensive measures and detection strategies:

- Enforce HTTPS with HSTS to complicate interception
- Log and alert on proxy-like traffic anomalies

## Objectives

1. Capture the exact follow request structure
2. Analyze request parameters for exploitation
3. Prepare request for concurrent replay

## Instructions

### Step 1: Configure Burp Proxy

**Context**: Set up Burp Suite to intercept browser traffic.

No command required; use Burp UI.

> Launch Burp Suite, navigate to Proxy > Options, ensure Intercept is on, and set listener to 127.0.0.1:8080. Configure browser proxy settings accordingly.

**Expected Output**: Burp is listening for traffic.

### Step 2: Perform Follow Action

**Context**: Trigger the request by liking/following a user.

No command required; interact via browser.

> With proxy active, click the follow/like button on a target user's profile on https://judge.me/people.

**Expected Output**: Request is paused in Burp's Intercept tab, showing POST details.

### Step 3: Forward and Save Request

**Context**: Release the request and save for later use.

No command required.

> In Burp, forward the request to complete the action, then copy the raw request to a file or directly to Turbo Intruder.

**Expected Output**: Original follow succeeds; request is saved.
