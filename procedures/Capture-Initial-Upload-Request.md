# Capture-Initial-Upload-Request

## Summary

This procedure captures the initial file upload request during account creation to establish a baseline for later replay attacks, focusing on intercepting Active Storage direct upload flows in Ruby on Rails applications.

## Description

In the context of exploiting authentication bypasses, this step involves setting up traffic interception to record the HTTP requests generated by a legitimate file upload. It targets web applications using Active Storage for S3 integration, where the upload process involves a POST to /rails/active_storage/direct_uploads followed by a PUT to S3. Prerequisites include proxy configuration and a valid target URL like https://app.hey.com/. Expected outcomes are captured requests ready for modification.

## Requirements

1. Burp Suite installed and running in proxy mode
2. Browser configured to route traffic through Burp proxy (e.g., 127.0.0.1:8080)
3. Access to create a new account on the target application
4. A test file for upload (e.g., image/svg+xml)

## Defense

Defensive measures and detection strategies:

- Implement strict proxy detection and block suspicious user-agents
- Monitor for unusual request patterns during account creation
- Use WAF rules to detect Burp Suite signatures in headers

## Objectives

1. Obtain the exact structure of the upload POST request including blob metadata
2. Capture the associated S3 PUT request from history for credential replacement
3. Prepare for request replay without triggering initial defenses

## Instructions

### Step 1: Configure Burp Suite Proxy

**Context**: Set up interception to capture all traffic to the target.

Intercept traffic while navigating to https://app.hey.com/ and completing account creation.

### Step 2: Perform Test Upload

**Context**: Trigger the upload to record requests.

Upload any file (e.g., SVG) and send the POST request to Repeater; also note the PUT in history.

**Expected Output**: POST request with JSON payload like {"blob":{"filename":"test.svg","content_type":"image/svg+xml","byte_size":338,"checksum":"base64md5"}}.
