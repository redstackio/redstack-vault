# Analyze Acronis Token Structure

## Summary

This procedure dissects the Acronis token obtained from registration to reveal its predictable components, specifically the sequential integer that enables IDOR attacks.

## Description

Tokens generated by the Acronis API follow a format like _mch-acronis.com-<timestamp>-<integer>, where the integer (e.g., 39235, 76556) increments sequentially across accounts. By registering multiple accounts, the pattern becomes evident, allowing attackers to guess integers for other users. This analysis targets the /api/v1/lead/ endpoint and highlights the lack of randomization in token generation.

## Requirements

1. At least one token URL from registration
2. Browser developer tools or text editor for inspection
3. Optional: Multiple registrations to confirm sequencing

## Defense

Defensive measures and detection strategies:

- Use cryptographically secure random values for tokens instead of sequential integers
- Log and audit token access patterns for anomalies
- Implement token validation tied to user sessions

## Objectives

1. Identify predictable elements in the token
2. Confirm sequential nature through examples
3. Prepare for brute-force modifications

## Instructions

### Step 1: Inspect Token URL

**Context**: Examine the full token structure post-registration.

Open the token URL in browser dev tools and note the format: https://www.acronis.com/en-us/api/v1/lead/id:929-HVV-335&token:_mch-acronis.com-<timestamp>-<integer>.

> Focus on the last 5 digits as the integer portion.

### Step 2: Register Additional Accounts

**Context**: Generate multiple tokens to observe sequencing.

Repeat registration with slight variations (e.g., different emails) and collect integers like 76556, 84755, 90306.

> Expected output: Increasing sequence confirming predictability.

### Step 3: Document Pattern

**Context**: Record the analysis for brute-force planning.

Note that integers are guessable and appended to timestamps, with no entropy.

> Success: Pattern like sequential 5-digit numbers identified.
