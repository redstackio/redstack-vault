# heroku-login

## Command

```bash
heroku login
```

## Description

Authenticates the user with Heroku via browser, required for app management operations.

## Parameters

| Parameter | Description | Required |
|-----------|-------------|----------|
| None | Opens browser for login | No |

## Examples

### Basic Usage

```bash
heroku login
```

## Expected Output

"Logged in as user@example.com".
