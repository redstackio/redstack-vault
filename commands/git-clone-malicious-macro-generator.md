# git-clone-malicious-macro-generator

## Command

```bash
git clone https://github.com/Mr-Un1k0d3r/MaliciousMacroGenerator
```

## Description

Clones the Malicious Macro Generator repository from GitHub to the local machine, downloading the Python tool and its templates for generating obfuscated VBA macros.

## Parameters

| Parameter | Description | Required |
|-----------|-------------|----------|
| https://github.com/Mr-Un1k0d3r/MaliciousMacroGenerator | The repository URL | Yes |

## Examples

### Basic Usage

```bash
git clone https://github.com/Mr-Un1k0d3r/MaliciousMacroGenerator
```

### With Specific Directory

```bash
git clone https://github.com/Mr-Un1k0d3r/MaliciousMacroGenerator mmg-tool
```
