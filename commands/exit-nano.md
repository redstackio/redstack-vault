# Exit Nano

## Command

```bash
# In nano: Press Ctrl+X
```

## Description

Exits the Nano editor, optionally saving if prompted.

## Parameters

| Parameter | Description | Required |
|-----------|-------------|----------|
| Ctrl+X | Exit shortcut | Yes |

## Examples

### Usage

Press Ctrl+X; answer Y to save if needed.

## Expected Output

Returns to shell prompt.
