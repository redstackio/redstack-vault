# npm-install-scrape-metadata

## Command

```bash
npm install scrape-metadata
```

## Description

Installs the scrape-metadata package from npm, used for extracting metadata from URLs in Node.js apps; vulnerable to XSS if output is unsanitized.

## Parameters

| Parameter | Description | Required |
|-----------|-------------|----------|
| scrape-metadata | Package name | Yes |

## Examples

### Basic Usage

```bash
npm install scrape-metadata
```

### Advanced Usage

```bash
npm install scrape-metadata --save
```

## Expected Output

Installation logs, e.g., "added 1 package", and node_modules/scrape-metadata directory created.
