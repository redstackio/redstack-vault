# npm-install-html-pages

## Command

```bash
npm install html-pages
```

## Description

Installs the html-pages Node.js package from the npm registry into the current directory, enabling local server setup for vulnerability exploitation.

## Parameters

| Parameter | Description | Required |
|-----------|-------------|----------|
| `html-pages` | Package name to install | Yes |

## Examples

### Basic Usage

```bash
npm install html-pages
```

### Advanced Usage

```bash
npm install html-pages@2.1.1
```

## Expected Output

Installation logs showing download progress, dependencies resolved, and node_modules created with html-pages binary.
