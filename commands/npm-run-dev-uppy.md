# npm-run-dev-uppy

## Command

```bash
npm run dev
```

## Description

Runs the development script to start the Uppy dev server, serving the dashboard at http://localhost:3452 for file upload testing.

## Parameters

| Parameter | Description | Required |
|-----------|-------------|----------|
| None | Executes dev script from package.json | No |

## Examples

### Basic Usage

```bash
npm run dev
```

## Expected Output

Starts server on port 3452, logs access URL.
