# coturn-quit

## Command

```bash
> q
```

## Description

Quits the interactive coturn telnet session after executing commands.

## Parameters

| Parameter | Description | Required |
|-----------|-------------|----------|
| `q` | Quit command | Yes |

## Examples

### Basic Usage

Within telnet: `> q`

## Expected Output

Session exit, returning to shell prompt.
