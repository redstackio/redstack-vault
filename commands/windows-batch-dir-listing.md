# windows-batch-dir-listing

## Command

```bash
smbclient \\_TARGET_IP\C$ -U $_DOMAIN/$_USERNAME%$_PASSWORD
```

## Description

This command mounts the C$ admin share on a remote Windows target using smbclient to retrieve output files generated by executed payloads, such as directory listings from batch commands.

## Parameters

| Parameter | Description | Required |
|-----------|-------------|----------|
| $_TARGET_IP | IP address of the target | Yes |
| $_DOMAIN | Domain name | Yes |
| $_USERNAME | Admin username | Yes |
| $_PASSWORD | Password (URL-encoded if special chars) | Yes |
| -N | Anonymous access (if no creds) | No |

## Examples

### Basic Usage

```bash
smbclient \\192.168.1.100\C$ -U corp/admin%Passw0rd
```

### Retrieve Specific File

After connecting: `get __output` then `rm __output` to clean up.

## Expected Output

File contains: 'dir' output like '2023/10/01  12:00    <DIR>          Windows'.
