# Save Changes to File in Nano

## Command

```bash
# In nano: Press Ctrl+O, then Enter to confirm
```

## Description

Saves the current buffer to the file in Nano editor.

## Parameters

| Parameter | Description | Required |
|-----------|-------------|----------|
| Ctrl+O | Save shortcut | Yes |

## Examples

### Usage

While in Nano, press Ctrl+O and confirm filename.

## Expected Output

File written to disk; confirmation message in Nano.
