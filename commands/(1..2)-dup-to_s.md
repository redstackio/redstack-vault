# (1..2)-dup-to_s

## Command

```ruby
(1..2).dup.to_s
```

## Description

Creates a Range object, duplicates it (failing initialization if method removed), and calls to_s to trigger a null pointer dereference and segfault in mruby.

## Parameters

| Parameter | Description | Required |
|-----------|-------------|----------|
| `1..2` | Range object to duplicate | Yes |
| `dup` | Duplicate the object | Yes |
| `to_s` | Convert to string, triggering crash | Yes |

## Examples

### Basic Usage

```ruby
(1..2).dup.to_s
```

### Advanced Usage

```ruby
# Preceded by method removal
Range.remove_method(:initialize_copy)
(1..2).dup.to_s
```

## Expected Output

Segfault and process crash.
