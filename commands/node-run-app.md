# node-run-app

## Command

```bash
node app.js
```

## Description

Runs the Node.js application file to start the Express.js server.

## Parameters

| Parameter | Description | Required |
|-----------|-------------|----------|
| `app.js` | The application file to run | Yes |

## Examples

### Basic Usage

```bash
node app.js
```

## Expected Output

Console message: 'App listening on port 8000'
