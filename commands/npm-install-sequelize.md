# npm-install-sequelize

## Command

```bash
npm i sequelize@4.32.7
```

## Description

Installs Sequelize ORM version 4.32.7 for database modeling in the PoC app.

## Parameters

| Parameter | Description | Required |
|-----------|-------------|----------|
| i | Install shorthand | Yes |
| sequelize@4.32.7 | Package and version | Yes |

## Examples

### Basic Usage

```bash
npm i sequelize@4.32.7
```

### Advanced Usage

```bash
npm i sequelize@4.32.7 --save-dev
```

## Expected Output

Installs sequelize v4.32.7; adds to dependencies.
