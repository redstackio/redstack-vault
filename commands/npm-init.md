# npm-init

## Command

```bash
npm init -y
```

## Description

Initializes a new NPM package with default settings.

## Parameters

| Parameter | Description | Required |
|-----------|-------------|----------|
| `-y` | Accept defaults without prompts | No |

## Examples

### Basic Usage

```bash
npm init -y
```

## Expected Output

Created package.json file with default values.
