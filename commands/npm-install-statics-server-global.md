# npm-install-statics-server-global

## Command

```bash
npm install statics-server -g
```

## Description

Installs the statics-server Node.js module globally, making it available as a command-line tool for serving static files.

## Parameters

| Parameter | Description | Required |
|-----------|-------------|----------|
| `-g` | Installs the package globally | Yes |
| `statics-server` | Package name | Yes |

## Examples

### Basic Usage

```bash
npm install statics-server -g
```

### Advanced Usage

```bash
npm install statics-server@0.0.9 -g
```
