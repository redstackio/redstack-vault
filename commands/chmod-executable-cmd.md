# Chmod Executable Cmd

## Command

```bash
chmod a+x /cmd
```

## Description

Makes /cmd script executable by all.

## Parameters

None.

## Examples

### Basic Usage

```bash
chmod a+x /cmd
```

## Expected Output

Permissions set to 777.
