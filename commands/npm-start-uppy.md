# npm-start-uppy

## Command

```bash
npm start
```

## Description

Starts the Uppy application server as defined in package.json scripts, preparing the environment for further dev operations.

## Parameters

| Parameter | Description | Required |
|-----------|-------------|----------|
| None | Uses default start script | No |

## Examples

### Basic Usage

```bash
npm start
```

## Expected Output

Launches the server, typically logging 'Server running' or similar.
