# deactivate-python-virtual-environment

## Command

```bash
deactivate
```

## Description

Deactivates the current Python virtual environment, returning to system Python.

## Parameters

| Parameter | Description | Required |
|-----------|-------------|----------|
| deactivate | Built-in command | Yes |

## Examples

### Basic Usage

```bash
deactivate
```

## Expected Output

```
$
```

Prompt returns to normal.
