# jadx-gui-decompile

## Command

```bash
jadx-gui BountyPay.apk
```

## Description

Decompile APK to Java source using JADX GUI for analysis.

## Parameters

| Parameter | Description | Required |
|-----------|-------------|----------|
| apk_path | Path to APK file | Yes |

## Examples

### Basic Usage

```bash
jadx-gui BountyPay.apk
```

## Expected Output

GUI with decompiled code, AndroidManifest.xml.
