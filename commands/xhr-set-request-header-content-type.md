# XHR Set Request Header Content-Type

## Command

```javascript
xhr.setRequestHeader("Content-Type", "application/x-www-form-urlencoded");
```

## Description

Sets the Content-Type header for form data.

## Parameters

| Parameter | Description | Required |
|-----------|-------------|----------|
| `header` | Content-Type | Yes |
| `value` | application/x-www-form-urlencoded | Yes |

### Basic Usage
