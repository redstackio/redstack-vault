# npm-install-takeapeek

## Command

```bash
npm install -g takeapeek
```

## Description

Installs the takeapeek Node.js module globally using npm, enabling its use as a command-line static web server for vulnerability demonstration.

## Parameters

| Parameter | Description | Required |
|-----------|-------------|----------|
| `-g` | Installs the package globally | Yes |
| `takeapeek` | Package name from npm registry | Yes |

## Examples

### Basic Usage

```bash
npm install -g takeapeek
```

### Advanced Usage

```bash
npm install -g takeapeek@0.2.2
```

## Expected Output

npm logs showing download, installation, and confirmation that takeapeek is added to global bin.
