# npm-install-sqlite3

## Command

```bash
npm i sqlite3
```

## Description

Installs the sqlite3 driver for using SQLite database in the test application.

## Parameters

| Parameter | Description | Required |
|-----------|-------------|----------|
| i | Install shorthand | Yes |
| sqlite3 | Package name | Yes |

## Examples

### Basic Usage

```bash
npm i sqlite3
```

### Advanced Usage

```bash
npm i sqlite3@5.0.0
```

## Expected Output

Installs sqlite3; may compile native bindings.
