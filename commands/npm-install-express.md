# npm Install Express

## Command

```bash
npm install express
```

## Description

Installs the Express.js package via npm for use in Node.js applications.

## Parameters

| Parameter | Description | Required |
|-----------|-------------|----------|
| `package` | Package name (express) | Yes |

## Examples

### Basic Usage

```bash
npm install express
```

## Expected Output

Express installed in node_modules directory.
