# mimikatz-extract-kerberos-tgt

## Code

```powershell
mimikatz.exe "kerberos::ptc c:\temp\TGT_darthsidious@lab.adsecurity.org.ccache"
```

## Description

This Mimikatz command uses the kerberos::ptc module to parse and extract a Kerberos Ticket Granting Ticket (TGT) from a ccache file generated by exploits like MS14-068. It loads the ticket into memory for use in pass-the-ticket attacks.

## Parameters

| Variable | Description | Example |
|----------|-------------|---------|
| c:\temp\TGT_...ccache | Path to the ccache file containing the TGT | c:\temp\TGT_user@domain.ccache |

## Usage

Run after obtaining a ccache from pykek or Metasploit. The extracted ticket allows authentication without passwords. Follow with "sekurlsa::pth" for ticket injection and shell spawning.

## Detection

- Kerberos ticket requests from unusual SIDs or sources (Event ID 4769).
- File access to .ccache files; Mimikatz process monitoring.
- Anomalous authentication logs showing pass-the-ticket.
