# cg_diff

**Status**: Unverified

## Overview

cg_diff is a utility tool included with Valgrind's Callgrind profiler. It compares two call-graph profile files generated by Callgrind to highlight differences in execution counts, function calls, and performance hotspots. In security contexts, it's useful for analyzing binary modifications, reverse engineering changes in malware behavior, or verifying exploit impacts on program execution paths.

## Description

cg_diff processes output from Callgrind, which profiles cache and branch-prediction behavior along with call graphs. By diffing two profiles (e.g., clean vs. exploited version), it reveals quantitative changes in code execution, helping security researchers understand how vulnerabilities alter program flow without manual code review. It supports options for brief output, percentage displays, and filtering to focus on significant deltas.

## Features

- Feature 1: Side-by-side comparison of function event counts and cumulative totals
- Feature 2: Percentage change calculations for easy identification of hotspots
- Feature 3: Filtering by threshold to ignore minor differences
- Feature 4: Support for brief or verbose output modes

## Installation

### Requirements

- Valgrind package (includes Callgrind and cg_diff)
- Perl (cg_diff is a Perl script)

### Install Commands

```bash
# On Ubuntu/Debian (Kali Linux included)
sudo apt update
sudo apt install valgrind

# Verify installation
which cg_diff
```

For other platforms, Valgrind is available via package managers like yum (RHEL/CentOS) or brew (macOS), but cg_diff is Linux-primary.

## Basic Usage

```bash
cg_diff --help
```

### Common Options

| Option | Description |
|--------|-------------|
| -h, --help | Show help message |
| --brief | Produce brief output, focusing on changes only |
| --show-percs | Display percentage changes |
| --threshold=N | Ignore differences below N events |

## Examples

### Example 1: Basic Usage

Compare two Callgrind outputs:

```bash
cg_diff callgrind.out.clean callgrind.out.modified
```

### Example 2: Advanced Usage

Show percentages and brief output:

```bash
cg_diff --show-percs --brief callgrind.out.1 callgrind.out.2 > changes.txt
```
