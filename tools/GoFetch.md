# GoFetch

**Status**: Unverified

## Overview

GoFetch is a command-line tool designed to automatically exercise attack plans generated by the BloodHound application. It is particularly useful in red team engagements targeting Active Directory environments, where it parses BloodHound's JSON output to generate and execute scripts for complex attack paths involving lateral movement, privilege escalation, and persistence.

## Description

BloodHound identifies potential attack paths in Active Directory by modeling relationships between users, groups, computers, and permissions. GoFetch takes this analysis further by automating the execution of those paths. It supports generating PowerShell scripts from parsed plans and running them with provided credentials, reducing manual effort in simulating real-world attacks. Common use cases include testing delegation paths (e.g., Kerberos delegation), group membership escalations, and resource-based constrained delegation exploits.

## Features

- Parsing of BloodHound JSON files to extract executable steps
- Generation of PowerShell scripts for Windows environments
- Direct execution of attack paths with credential injection
- Verbose logging and error handling for troubleshooting
- Support for common AD attack techniques like Kerberoasting and DCSync

## Installation

### Requirements

- Go 1.16 or higher
- Git
- Access to BloodHound output files (JSON format)
- For execution: PowerShell 5.1+ on target Windows systems

### Install Commands

```bash
# Clone and build from source (recommended for latest features)
git clone https://github.com/GoFetch/GoFetch.git
cd GoFetch
make build

# Or install pre-built binary (if available)
# Download from releases and add to PATH

# Alternative: Go install (if module supports)
go install github.com/GoFetch/GoFetch/cmd/gofetch@latest
```

On Kali Linux or Ubuntu:

```bash

# Then follow clone/build steps above
```

On Windows (using PowerShell):

```powershell

# Then:

```

## Basic Usage

```bash
gofetch --help
```

This displays available subcommands: `parse`, `generate-ps`, `execute`.

### Common Options

| Option | Description |
|--------|-------------|
| `-h, --help` | Show help message |
| `-v, --verbose` | Enable verbose output for debugging |
| `--log` | Path to log file |

## Examples

### Example 1: Basic Usage (Parse and Generate)

First, parse a BloodHound path:

```bash
gofetch parse bloodhound-shortest-path-to-domain-admins.json -o plan.yaml
```

Then generate a PowerShell script:

```bash
gofetch generate-ps plan.yaml -o attack.ps1
```

### Example 2: Advanced Usage (Full Execution)

Execute the path directly (assumes script is ready):

```bash
gofetch execute attack.ps1 --domain corp.local --user lowpriv --pass Password123 --verbose
```

## Detection

Indicators and methods for detecting this tool's usage:

- Unusual PowerShell script execution with AD module imports (e.g., ActiveDirectory)
- Network traffic patterns matching BloodHound path steps (e.g., multiple Kerberos requests)
- Log entries for `gofetch.exe` or generated scripts in event logs (Event ID 4688)
- Anomalous credential usage across multiple hosts
