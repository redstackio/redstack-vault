# galleta

**Status**: Unverified

## Overview

Galleta is a forensic analysis tool designed to parse and extract data from cookie files generated by Microsoft Internet Explorer. It is particularly useful in digital forensics investigations for recovering browsing history, session information, and potential credential artifacts stored in cookies. Common use cases include post-incident analysis, malware investigations involving web-based attacks, and evidence collection in security assessments.

## Description

Galleta processes the proprietary cookie file format used by Internet Explorer (typically located in %USERPROFILE%\Cookies or similar paths). It decodes the binary structure to output human-readable, field-separated data including cookie name, value, domain, path, expiration date, and creation/modification timestamps. The output is tab-delimited by default, making it easy to import into spreadsheets like Excel for further analysis. Galleta does not support modern browsers like Chrome or Firefox directly but focuses on legacy IE formats. It is part of the Sleuth Kit suite and is valuable for red teamers simulating forensic evasion or blue teams performing artifact analysis.

## Features

- Parses IE cookie files (.dat format) into structured output
- Extracts key fields: name, value, host, path, expires, created, modified
- Outputs in tab-separated format for easy import into analysis tools
- Handles multiple cookie files in batch mode
- Lightweight and command-line driven for scripting in forensic workflows

## Installation

### Requirements

- Linux environment (Kali recommended) with basic C libraries
- No additional dependencies beyond standard build tools

### Install Commands

On Kali Linux, Galleta is pre-installed as part of the Sleuth Kit.

```bash
# If not pre-installed, install via apt (Kali/Debian)
apt update && apt install sleuthkit

# Verify installation
which galleta
```

For Ubuntu:

```bash
apt update && apt install sleuthkit
```

For manual build from source (Sleuth Kit):

```bash
# Download from official repo
git clone https://github.com/sleuthkit/sleuthkit.git
cd sleuthkit
./bootstrap
./configure
make
sudo make install
```

On Windows, use Cygwin or WSL with the above Linux instructions.

## Examples

### Example 1: Basic Usage

Parse a single IE cookie file and output to stdout:

```bash
galleta /path/to/cookies.dat
```

### Example 2: Advanced Usage

Redirect output to a file for spreadsheet import:

```bash
galleta /path/to/cookies.dat > cookies_output.tsv
```

Process multiple files:

```bash
galleta file1.dat file2.dat > combined_cookies.tsv
```
