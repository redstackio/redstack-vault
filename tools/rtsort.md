# rtsort

**Status**: Unverified

## Overview

rtsort is a utility within the RainbowCrack suite designed to sort rainbow table files generated by the rtgen tool. It implements the time-memory trade-off technique for efficient hash cracking by organizing chains in rainbow tables based on ending hashes. This tool is commonly used in password recovery and security testing scenarios to prepare tables for cracking operations with rcrack.

## Description

RainbowCrack, including rtsort, leverages Philippe Oechslin's faster time-memory trade-off algorithm to crack hashes using precomputed rainbow tables. Unlike brute-force crackers that compute hashes on-the-fly and discard results, rtsort helps in the post-generation phase by sorting the tables, which is essential for the lookup efficiency during cracking. It processes one or more table files, sorting chains to enable quick reduction and lookup. This differs from brute-force by requiring upfront computation but offering superior performance for large-scale cracking. rtsort is particularly useful after generating raw tables with rtgen, ensuring they are optimized for use in credential access techniques during penetration testing or forensic analysis.

## Features

- Sorts rainbow table chains by ending hash for efficient lookup
- Supports multiple input table files in a single run
- Optional compression to reduce table size post-sorting
- Verbose output for monitoring progress on large tables
- Integrates seamlessly with other RainbowCrack tools like rtgen and rcrack

## Basic Usage

```bash
rtsort --help
```

### Common Options

| Option | Description |
|--------|-------------|
| `-v` | Verbose output showing progress |
| `-compress` | Compress the sorted tables to save space |
| No options | Basic sorting of input files |

## Examples

### Example 1: Basic Usage

Sort a single rainbow table file:

```bash
rtsort mytable.rt
```

This reads the raw table, sorts the chains, and overwrites or creates a sorted version.

### Example 2: Advanced Usage

Sort and compress multiple tables with verbose output:

```bash
rtsort -v -compress table1.rt table2.rt table3.rt
```
