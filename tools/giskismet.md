# giskismet

**Status**: Unverified

## Overview

GISKismet is an open-source tool for visualizing wireless reconnaissance data collected by Kismet. It enables security testers to import Kismet logs into a SQLite database, perform SQL-based analysis, and export geospatial visualizations as KML files for tools like Google Earth. Commonly used in wireless penetration testing to map access points, signal coverage, and client devices during reconnaissance phases.

## Description

GISKismet processes Kismet's raw log files (containing wireless network discoveries, SSIDs, MAC addresses, GPS coordinates, and signal data) and structures them into a queryable SQLite database. Users can then run custom SQL queries to filter and analyze data, such as identifying high-signal access points or tracking device movements. The tool supports exporting results to KML format, allowing overlay on maps for visual correlation of wireless findings with physical locations. It's particularly useful for red team operations involving wardriving or indoor wireless mapping, providing a flexible alternative to Kismet's built-in visualization.

## Features

- **Log Import**: Converts Kismet dump files to SQLite with support for access points, clients, and GPS-tagged data.
- **SQL Querying**: Full SQLite access for custom data extraction and analysis (e.g., filtering by SSID, channel, or signal strength).
- **Geospatial Export**: Generates KML files with placemarks for APs and polygons for signal coverage, compatible with Google Earth and similar tools.
- **Flexible Visualization**: Supports scripting for automated report generation based on query results.
- **Lightweight**: Relies on Python and SQLite, with no heavy dependencies.

## Installation

### Requirements

- Python 3.x
- SQLite3 (usually pre-installed on Linux)
- Kismet logs (generated by the Kismet wireless sniffer)
- Git (for cloning the repository)

### Install Commands

On Kali Linux or Ubuntu:

```bash
# Clone the repository
git clone https://github.com/ictiologia/giskismet.git /opt/giskismet

# Navigate to directory
cd /opt/giskismet

# Install any Python dependencies (if needed; typically none)
pip3 install -r requirements.txt  # If requirements.txt exists; otherwise, run directly
```

For other platforms, ensure Python and SQLite are available. No compilation required.

## Basic Usage

```bash
giskismet_convert.py <kismet_log_file> <output_db>
```

This imports data. Then query with SQLite:

```bash
sqlite3 output_db "SELECT * FROM aps;"
```

Export to KML using provided scripts or custom SQL.

## Examples

### Example 1: Basic Usage

Import a Kismet log:

```bash
python3 /opt/giskismet/giskismet_convert.py Kismet-20231001.log wireless.db
```

Query access points:

```bash
sqlite3 wireless.db "SELECT mac, ssid, maxsignal FROM aps WHERE ssid LIKE '%Corp%';"
```

### Example 2: Advanced Usage

Generate KML for visualization:

```bash
python3 /opt/giskismet/giskismet_kml.py wireless.db aps_export.kml
```

Open aps_export.kml in Google Earth to view AP locations on a map.
