# rce0923234.html

**Status**: Unverified

## Overview

HTML file with embedded JavaScript for remote exploitation of EvoStream WebSocket, enabling RCE as SYSTEM via user-visited page.

## Description

Hosts JS that creates WebSocket to ws://localhost:7440 and sends launchprocess commands, e.g., to run calc.exe. Requires hosting on a remote server for phishing delivery.
