# morphHTA

**Status**: Unverified

## Overview

morphHTA is a specialized tool for morphing and obfuscating the 'evil.HTA' payload generated by Cobalt Strike. It is primarily used in red team operations to modify HTA (HTML Application) files, making them harder for antivirus and endpoint detection tools to identify by altering code structure, variable names, and injecting non-functional code.

## Description

The tool targets the default HTA payload from Cobalt Strike, which is often flagged due to static signatures. By applying transformations like string encoding, dead code insertion, and randomization, morphHTA creates variants that maintain functionality while reducing detection rates. It is particularly useful for initial access vectors involving user interaction, such as phishing emails with HTA attachments. Supported on Windows environments where HTA files can execute via mshta.exe.

## Features

- Variable and function name randomization
- String obfuscation and encoding
- Insertion of junk code to alter file signatures
- Preservation of payload functionality (e.g., beacon callbacks)
- Batch processing for multiple variants
