# cg-annotate

**Status**: Unverified

## Overview

cg_annotate is a utility tool within the Valgrind suite, specifically designed for use with the Callgrind profiler. It processes Callgrind's output files to annotate source code with detailed call-graph and performance data, such as function call counts, execution times, and percentages. In security testing, it is useful for analyzing the runtime behavior of binaries, debugging custom exploits, or optimizing tools during red team operations.

## Description

cg_annotate reads profile data generated by Callgrind (a cache and call-graph profiler in Valgrind) and overlays it onto source code files or displays it in tree format. This allows developers and security researchers to identify performance bottlenecks, understand call flows, and correlate code paths with execution metrics. It supports C/C++ source annotation and can output to terminals or files. While not a direct attack tool, it aids in reverse engineering, malware analysis, and exploit development by providing insights into program dynamics without runtime overhead during analysis.

## Features

- Feature 1: Source code annotation with inline call counts and percentages.
- Feature 2: Tree-based visualization of caller/callee relationships.
- Feature 3: Support for filtering and sorting by cost metrics (e.g., instructions, calls).
- Feature 4: Integration with Valgrind's event counters for custom profiling.

## Installation

### Requirements

- Linux system with Valgrind installed (cg_annotate is bundled with it).
- GCC or compatible compiler for building if installing from source.

### Install Commands

```bash
# On Ubuntu/Debian (includes Valgrind and cg_annotate)
sudo apt update
sudo apt install valgrind

# On Kali Linux (pre-installed or via apt)
sudo apt install valgrind

# From source (if needed)
cd /tmp
wget https://sourceware.org/pub/valgrind/valgrind-3.21.0.tar.bz2
 tar -xjf valgrind-3.21.0.tar.bz2
cd valgrind-3.21.0
./configure
make
sudo make install
```

After installation, cg_annotate is available as a script in /usr/bin/.

## Basic Usage

```bash
cg_annotate --help
```

This displays the help menu with all options.

### Common Options

| Option | Description |
|--------|-------------|
| -h, --help | Show help message |
| --show-percs=yes | Include percentage calculations in output |
| --tree=both | Display both caller and callee trees |
| --context=N | Show N lines of context around annotations |

## Examples

### Example 1: Basic Usage

First, generate a Callgrind profile:

```bash
valgrind --tool=callgrind ./myprogram
```

Then annotate:

```bash
cg_annotate callgrind.out.1234 main.c
```

### Example 2: Advanced Usage

View call tree:

```bash
cg_annotate --tree=both callgrind.out.1234
```
