# hackerone

**Status**: Unverified

## Overview

HackerOne is a bug bounty and vulnerability disclosure platform that facilitates secure reporting of security issues to organizations.

## Description

Used in ethical hacking to report subdomain takeover vulnerabilities, such as the 8x8 incident with easycontactnow.com, allowing researchers to submit detailed proofs without exploitation.

## Features

- Feature 1: Secure report submission with attachments
- Feature 2: Triage and communication with vendors
- Feature 3: Bounty programs and reputation tracking
