# t50

**Status**: Unverified

## Overview

Brief overview of the tool, its primary purpose, and common use cases in security testing.

t50 is a multi-protocol packet injector tool for Unix-like systems, supporting 15 protocols for network stress testing, packet crafting, and denial-of-service simulations in red team exercises and penetration testing.

## Description

Detailed description of the tool's capabilities, features, and how it's typically used in offensive security operations.

t50 enables the injection of custom packets across protocols like TCP, UDP, ICMP, IGMPv2/v3, EGP, DCCP, RSVP, RIPv1/v2, GRE, ESP, AH, EIGRP, and OSPF. It supports flooding for high-volume attacks, CIDR ranges for targeting subnets, TCP option customization, and achieves high performance with up to 1,000,000 packets per second on suitable hardware. In offensive security, it's used for network reconnaissance, service disruption testing, and protocol fuzzing to identify weaknesses.

## Features

- Feature 1: Flooding mode for sustained packet storms to simulate DoS attacks
- Feature 2: CIDR support for targeting entire IP ranges efficiently
- Feature 3: Protocol support for 15 network protocols including TCP/UDP/ICMP and routing protocols like OSPF/EIGRP
- Feature 4: Customizable TCP options (e.g., flags, window size) for advanced packet crafting
- Feature 5: High-performance engine optimized for raw socket injection

## Installation

### Requirements

- Unix-like system (Linux recommended)
- Root privileges for raw packet socket access
- GCC compiler if building from source

### Install Commands

```bash
# On Kali Linux (pre-installed)
sudo apt update

# On Ubuntu/Debian
sudo apt update
sudo apt install t50

# From source (GitHub repo)
git clone https://github.com/deltacomplex/t50.git
cd t50
./autogen.sh
./configure
make
sudo make install
```

## Basic Usage

```bash
t50 --help
```

### Common Options

| Option | Description |
|--------|-------------|
| -f, --flood | Enable continuous flooding mode for DoS simulation |
| -S <ip> | Specify source IP address (spoofing) |
| -d <dest> | Destination IP or CIDR range |
| --protocol <num> | Protocol number (e.g., 1 for ICMP, 6 for TCP, 17 for UDP) |
| -p <port> | Destination port (for TCP/UDP) |
| -h, --help | Display help and usage |

## Examples

### Example 1: Basic Usage

ICMP echo request to a target:

```bash
sudo t50 1 -S 192.168.1.100 192.168.1.1
```

### Example 2: Advanced Usage

UDP flood on a CIDR range:

```bash
sudo t50 17 --flood -p 53 192.168.1.0/24
```
